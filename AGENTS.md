# AGENTS.md

## Структура репозитория

- Это статический одностраничный лендинг, а не Unity-проект. `index.html` — точка входа приложения; в нём находятся разметка страницы и скрипты поведения.
- Стилизация использует Tailwind CSS 3: utility-классы из HTML компилируются через `src/input.css` в сгенерированный `style.css`, который является единственной подключённой таблицей стилей. Не редактируй `style.css` вручную; изменяй классы в `index.html` или директивы Tailwind в `src/input.css`, затем пересобирай CSS.
- Запускай `npm run build:css` для создания минифицированной таблицы стилей и `npm run watch:css` во время разработки. `package-lock.json` фиксирует версии инструментов Tailwind.
- `tailwind.config.js` задаёт цвета `brand`, utility-класс фона `img/logo.png` и пользовательские точки перелома `mobile` (481px) и `tablet` (769px), которые используются на странице.
- Ресурсы страницы находятся в `img/` и подключаются относительными путями; сохраняй эти пути рабочими. Язык страницы — русский (`lang="ru"`), поэтому сохраняй текст в UTF-8, если не требуется изменение контента.

## Поведение и особенности редактирования

- Навигация зависит от ID фрагментов `home`, `services`, `portfolio`, `news` и `contact`; `contact` находится на адресе в футере. При переносе секций сохраняй соответствующие ID.
- Фиксированная шапка учитывается классом Tailwind `mt-20` у `main` и значением `headerOffset = 80` в скрипте плавной прокрутки. При изменении высоты шапки обновляй оба значения.
- Мобильное меню управляется элементом `.mobile-menu-btn`, который переключает классы `hidden`/`block` у `.nav-mobile`; сохраняй эти селекторы и обновляй `aria-expanded` при изменении элемента управления.
- Изображения и ссылки портфолио жёстко заданы в `index.html` (`img/1.png`–`img/8.png`). Проект 4 использует URL с `http://` и обработчик клика с вызовом `window.open`; считай это поведение намеренным, пока владелец не попросит его изменить.
- Сейчас брендинг смешан: в заголовке и шапке указано «Disarmed Team», а в футере — «Ember Studio». Не нормализуй это в рамках посторонней правки.
- Ссылки социальных сетей в футере являются-заглушками (`#`), а адрес содержит слово «Примерная»; не считай их реальными интеграционными данными.
- `robots.txt` сейчас запрещает доступ всех поисковых роботов (`Disallow: /`); изменяй его только по явному запросу, связанному с SEO или публикацией сайта.

## Проверка

- В проекте нет тестов, линтера, форматтера и CI. После изменения Tailwind-классов запускай `npm run build:css` и проверяй `index.html` в браузере.
- После сборки проверяй загрузку изображений, десктопное и мобильное меню, прокрутку по якорям, смещение фиксированной шапки и внешние ссылки портфолио/чата.
